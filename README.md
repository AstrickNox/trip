# 제주 여행 노트

[웹페이지](https://astricknox.github.io/trip/jeju/)

제주 3박 4일 여행 코스 5가지, 관광지·식당 안내와 사진 갤러리.

source 디렉터리에서 `node build.mjs`와 `node enrich.mjs`를 실행한 뒤 dist/index.html을 jeju/index.html로 복사하면 됩니다.

사진은 각 출처를 페이지에 표시했습니다. 인원·가족관계·나이 정보는 현재 페이지와 소스에서 제거했습니다.

모든 코스의 9월 23일은 허니문하우스 10시 늦은 조식 후 11시 공항 방향 출발입니다. D안은 9월 20일 스누피가든을 방문합니다.

E안은 숙소 거리보다 최근 화제성을 우선한 제주당·제주동화마을·런던베이글·해지개 코스입니다. 선정 근거 링크를 페이지에 표시했습니다.
