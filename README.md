# 가족 여행 노트

[제주 여행 웹페이지](https://astricknox.github.io/trip/)

2026년 9월 20–23일 · 성인 4명 + 아이 2명. 소노벨 제주 2박, 서귀포 KAL 1박.

3가지 4일 코스, 관광지 10곳, 맛집 8곳, 사진 9장, 실용 상세 안내를 제공합니다. 미디어아트는 후보 목록에만 있습니다.

## 수정

Node.js에서 source 폴더를 작업 디렉터리로 사용해 `node build.mjs`, `node enrich.mjs` 순으로 실행하면 source/dist/index.html이 생성됩니다. 이를 저장소 루트 index.html로 복사해 커밋하면 GitHub Pages가 배포합니다.

사진은 Wikimedia Commons CC0 함덕 사진과 VisitJeju 원문 이미지 링크를 사용하며 각 출처를 페이지에 표시했습니다. VisitJeju 사진의 권리는 각 권리자에게 있으며 재사용 라이선스를 부여하지 않습니다.
